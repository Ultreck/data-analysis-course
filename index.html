STAGE 1 — Foundations

Week 1–4 · What Data Analysis Is, Statistics & Excel

Step 1 — What Is Data Analysis? Conceptual

Before writing a single formula or line of code, you need to understand what a Data Analyst actually does and why it matters.

Data Analysis is the process of inspecting, cleaning, transforming, and modeling data to discover useful information, draw conclusions, and support decision-making.

🔍 Analogy

Think of data like raw crude oil from the ground. It has value, but in its raw state you cannot use it. A data analyst is like the refinery — taking that raw oil (data), processing it, removing impurities (cleaning), and turning it into fuel (insights) that powers business decisions.

Types of Data Analysis:

DescriptiveWhat happened?
DiagnosticWhy did it happen?
PredictiveWhat will happen?
PrescriptiveWhat should we do?

Roles to Know:

Step 2 — Mathematics & Statistics Core Theory

You do not need to be a mathematician. But you need to understand the language that data speaks. Statistics is that language.

🔍 Analogy

Statistics is to data analysis what grammar is to English. You can speak informally without it, but if you don't know the rules, you'll misunderstand and mislead. Without statistics, you might look at data and draw completely wrong conclusions.

Topics to Cover:

  • Descriptive Statistics: Mean, Median, Mode, Range, Variance, Standard Deviation
  • Percentiles & Quartiles: IQR, Outlier Detection (Box Plot)
  • Probability Basics: Events, probability rules, conditional probability
  • Distributions: Normal distribution (bell curve), Skewness, Kurtosis
  • Inferential Statistics: Hypothesis testing, p-value, confidence intervals
  • Correlation vs Causation: R-value, Pearson Correlation, Scatter plots
🔍 Analogy — Mean vs Median

Imagine 10 students' test scores: 40, 45, 50, 55, 60, 62, 65, 68, 70, 200. The mean is 71.5 — pulled up by the outlier (200). The median is 61. Which one actually represents the class better? The median! This is why data analysts must choose the right measure of central tendency.

Step 3 — Microsoft Excel / Google Sheets Practical

Excel is the most widely used data tool in the world. Even companies that use Python and Power BI still use Excel daily. It is your first real data tool.

🔍 Analogy

Excel is like learning to cook on a regular stove before using an industrial kitchen. Once you master this, everything else feels powerful by comparison.

What to Learn in Excel:

  • Navigation, cell references (relative vs absolute: A1 vs $A$1)
  • Formulas: SUM, AVERAGE, COUNT, COUNTA, IF, IFS, AND, OR
  • Lookup functions: VLOOKUP, HLOOKUP, INDEX-MATCH, XLOOKUP
  • Text functions: LEFT, RIGHT, MID, TRIM, CONCATENATE, TEXT
  • Date functions: TODAY, NOW, DATEDIF, YEAR, MONTH, DAY
  • Data Cleaning: Remove Duplicates, Text to Columns, Find & Replace
  • Pivot Tables — summarizing thousands of rows in seconds
  • Charts: Bar, Line, Pie, Scatter, Histogram
  • Conditional Formatting — highlighting patterns visually
  • Data Validation — controlling what users can enter
🔍 Analogy — Pivot Tables

A Pivot Table is like a magic summarizer. Imagine you have 10,000 rows of sales data with product names, regions, and amounts. A Pivot Table lets you instantly see "total sales per region per product" without writing a single formula — just drag and drop. It is one of the most powerful tools any analyst can master.

STAGE 2 — SQL (Structured Query Language)

Week 5–8 · Talk to Databases Like a Pro

Step 4 — SQL Fundamentals Core Skill

SQL is the language you use to communicate with databases. Almost every company stores data in a database, and as an analyst, SQL is your most important technical skill. No SQL = no job.

🔍 Analogy

Think of a database as a massive library with millions of books (rows of data). SQL is how you ask the librarian for exactly what you need: "Give me all books written after 2010 by Nigerian authors, sorted by title." Without SQL, you'd have to manually search every shelf.

Basic SQL — The Building Blocks:

-- Select all columns from a table SELECT * FROM customers; -- Select specific columns SELECT name, email, city FROM customers; -- Filter with WHERE SELECT * FROM orders WHERE total_amount > 1000; -- Sort results SELECT * FROM products ORDER BY price DESC; -- Limit rows returned SELECT * FROM sales LIMIT 10;

Intermediate SQL — Aggregation & Grouping:

-- Count rows SELECT COUNT(*) FROM orders; -- Total sales per region SELECT region, SUM(revenue) AS total_revenue FROM sales GROUP BY region HAVING SUM(revenue) > 50000 ORDER BY total_revenue DESC;

SQL JOINs — The Most Important Concept:

🔍 Analogy — JOINs

Imagine you have two notebooks: one has student names and IDs, another has student scores and IDs. A JOIN combines them using the ID — so you can see each student's name alongside their score. INNER JOIN gives you only students in both books. LEFT JOIN gives you all students from the first book, even if they have no score.

-- INNER JOIN — only matching rows SELECT c.name, o.order_date, o.amount FROM customers c INNER JOIN orders o ON c.id = o.customer_id; -- LEFT JOIN — all customers, even without orders SELECT c.name, o.amount FROM customers c LEFT JOIN orders o ON c.id = o.customer_id;

Advanced SQL — Window Functions & CTEs:

-- Rank salespeople by revenue SELECT name, revenue, RANK() OVER (ORDER BY revenue DESC) AS rank FROM salespeople; -- CTE — Common Table Expression WITH top_customers AS ( SELECT customer_id, SUM(amount) AS total FROM orders GROUP BY customer_id ) SELECT c.name, t.total FROM top_customers t JOIN customers c ON c.id = t.customer_id;

STAGE 3 — Python for Data Analysis

Week 9–16 · Pandas, NumPy & Data Wrangling

Step 5 — Python Basics Programming

Python is the dominant programming language in data analysis. It is readable, powerful, and has an enormous ecosystem of libraries built specifically for working with data.

🔍 Analogy

If Excel is a calculator, Python is a full factory floor. Python doesn't just compute one formula — it can automate an entire workflow: pull data from an API, clean it, analyze it, generate 50 charts, and email a report — all in one script while you sleep.

Core Python Concepts for Analysts:

# Variables and data types name = "Emmanuel" age = 21 revenue = 45000.50 is_active = True # Lists (like arrays) scores = [85, 90, 78, 92, 88] print(sum(scores) / len(scores)) # Average # Dictionaries (key-value pairs) student = {"name": "Ada", "score": 95, "grade": "A"} print(student["name"]) # Loops for score in scores: print(score) # Functions def get_average(data): return sum(data) / len(data)

Step 6 — NumPy & Pandas Data Libraries

These two libraries are the backbone of data analysis in Python. You cannot do serious data work without them.

🔍 Analogy — Pandas

Pandas is Excel inside Python — but with superpowers. A Pandas DataFrame is like a spreadsheet: rows and columns of data. The difference? Python can process millions of rows in seconds, do complex transformations, and integrate with every other tool in the data ecosystem.

NumPy — Numerical Computing:

import numpy as np arr = np.array([10, 20, 30, 40, 50]) print(np.mean(arr)) # 30.0 print(np.std(arr)) # Standard deviation print(np.max(arr)) # 50 # Create arrays fast zeros = np.zeros((3, 4)) # 3x4 matrix of zeros rng = np.arange(0, 100, 5) # [0, 5, 10 ... 95]

Pandas — Data Manipulation:

import pandas as pd # Load a CSV file df = pd.read_csv("sales_data.csv") # Quick overview df.head() # First 5 rows df.shape # (rows, columns) df.info() # Data types and nulls df.describe() # Summary stats # Filter rows high_sales = df[df["revenue"] > 10000] # Group and aggregate region_sales = df.groupby("region")["revenue"].sum() # Handle missing values df.dropna() # Drop rows with nulls df.fillna(0) # Fill nulls with 0 df["col"].fillna(df["col"].mean()) # Fill with mean

STAGE 4 — Data Visualization

Week 13–18 · Tell Stories With Data

Step 7 — Visualization Principles & Python Libraries Visual

Data without visualization is like a map without a legend. Your audience cannot act on numbers alone — you need to turn data into pictures that communicate insights instantly.

🔍 Analogy

Imagine presenting Nigeria's population growth from 1960 to 2024 as a table of 64 numbers vs a single line chart. The chart tells the story in 1 second. A table takes 3 minutes to comprehend. Visualization is not decoration — it is communication.

When to Use Which Chart:

Chart TypeBest Used ForExample
Bar ChartComparing categoriesSales by region
Line ChartTrends over timeMonthly revenue
Scatter PlotRelationship between 2 variablesHeight vs Weight
HistogramDistribution of a single variableAge distribution
Pie/DonutPart-to-whole (use sparingly)Market share
HeatmapCorrelation matrix, patternsFeature correlations
Box PlotDistribution + outliersSalary ranges by department

Matplotlib — Basic Plotting:

import matplotlib.pyplot as plt months = ["Jan", "Feb", "Mar", "Apr"] revenue = [45000, 52000, 49000, 61000] plt.figure(figsize=(10, 5)) plt.plot(months, revenue, marker="o", color="#6c63ff") plt.title("Monthly Revenue 2024") plt.xlabel("Month") plt.ylabel("Revenue (₦)") plt.grid(True, alpha=0.3) plt.tight_layout() plt.show()

Seaborn — Statistical Visualization:

import seaborn as sns # Correlation heatmap sns.heatmap(df.corr(), annot=True, cmap="coolwarm") # Distribution plot sns.histplot(df["age"], bins=20, kde=True) # Box plot sns.boxplot(x="department", y="salary", data=df) # Scatter plot with color by category sns.scatterplot(x="experience", y="salary", hue="gender", data=df)

STAGE 5 — BI Tools (Power BI & Tableau)

Week 17–22 · Dashboards & Business Intelligence

Step 8 — Power BI BI Tool

Power BI is Microsoft's Business Intelligence tool. It is free to download, widely adopted in corporate Africa and globally, and one of the most in-demand skills for analysts.

🔍 Analogy

If Python charts are hand-painted artwork, Power BI is a printing press. Power BI lets non-technical stakeholders (CEOs, managers) interact with live data through beautiful dashboards — no code needed. As an analyst, your job is to build those dashboards.

Power BI Core Concepts:

  • Data Sources: Connect to Excel, CSV, SQL Server, APIs, SharePoint, Google Sheets
  • Power Query: Data transformation layer (ETL) — filter, merge, unpivot, clean
  • Data Model: Define relationships between tables (star schema)
  • DAX (Data Analysis Expressions): Formula language for calculated columns & measures
  • Visuals: Bar, Line, Map, Card, Matrix, Slicers, KPI charts
  • Reports vs Dashboards: Reports are multi-page; dashboards are pinned summary views
  • Publishing: Share reports via Power BI Service (web)

Key DAX Formulas:

// Total Revenue Total Revenue = SUM(Sales[Revenue]) // Revenue Growth % Revenue Growth = DIVIDE( [Total Revenue] - [Last Year Revenue], [Last Year Revenue] ) * 100 // YTD Revenue YTD Revenue = TOTALYTD(SUM(Sales[Revenue]), Dates[Date]) // Count distinct customers Unique Customers = DISTINCTCOUNT(Sales[CustomerID])

Step 9 — Tableau BI Tool

Tableau is widely regarded as the most visually powerful BI tool available. Many analytics teams prefer it for its drag-and-drop dashboard creation and stunning visual output.

🔍 Analogy

Tableau is like Canva for data. Power BI is like Microsoft Word for data. Both get the job done — but Tableau leans more toward beautiful visual storytelling, while Power BI leans toward deep Microsoft ecosystem integration.

Tableau Core Concepts:

  • Dimensions (categorical) vs Measures (numeric)
  • Marks card, Rows & Columns shelf
  • Calculated Fields (Tableau's version of DAX)
  • Filters: Context filters, Quick filters, Top N
  • Parameters — dynamic user inputs
  • Dashboard actions — interactive filtering between charts
  • Story Points — narrative data presentations
  • Tableau Public — free hosting for portfolio projects
